# LSTM (Long-Short Term Memory)

> 순차 hidden state로 temporal context를 보존하는 디코더. 하위 노드: [[02 - BCI Decoding]]

## 구조

- 입력: `(N, 20, 161)` sequential tensor.
- 2-layer LSTM, hidden=128.
- 마지막 step 출력 → FC → 2D velocity.

## Gate 구조

- Forget gate: 이전 cell state 유지/삭제 비율.
- Input gate: 현재 정보 누적 비율.
- Output gate: 다음 hidden state로 내보낼 비율.
- tanh + sigmoid로 장기/단기 기억 분리.

## Trade-off

- short seq(T=20)에서는 Transformer과 비슷하거나 약간 낮음.
- baseline r=0.8945, SER=1e-2 retention 0.9979.
- T가 짧아서 LSTM의 장기 의존 장점이 발휘되지 않음.
