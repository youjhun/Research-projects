## 프로젝트 목적성

### 핵심 질문 하나로 정의

```
"스파이크 전송 오류가 늘어날수록
 운동 디코딩 성능이 얼마나 떨어지는가?"

→ 논문 Fig.4f를 실제 영장류 데이터로 재현
```

### 왜 이 질문이 중요한가

```
무선 BCI의 현실:
전송 채널에서 스파이크 손실/오검출 불가피
         ↓
"어느 수준까지 허용 가능한가?"
         ↓
SER vs 디코딩 성능의 정량적 관계 필요
         ↓
논문은 영장류 데이터로 검증했지만
코드와 방법론은 공개 안 됨
         ↓
본 프로젝트: 오픈소스 데이터로 독립 재현
```

### 3줄 목적 요약

```
① 검증: Lee et al. 2024의 핵심 주장
         (SER 10⁻³에서 88.8% 성능 유지)을
         독립된 데이터셋으로 재현

② 확장: 원논문(Fagg 2009)과 다른
         pmd-1 데이터로 일반화 가능성 검토

③ 기여: 공개되지 않은 재현 코드를
         파이썬으로 구현 및 공개
```

## 이 프로젝트의 차별점

```
기존 논문과 다른 점:

① 데이터셋 다름
   논문: Fagg 2009 (M1 + S1, center-out)
   본 연구: pmd-1 (M1 + PMd, sequential reaching)
   → 다른 과제에서도 같은 결과가 나오는가?

② 디코더 다름
   논문: SNN (Spiking Neural Network)
   본 연구: Ridge Regression (선형)
   → 디코더 종류가 SER 내성에 영향을 주는가?

③ 언어 다름
   논문: MATLAB (코드 비공개)
   본 연구: Python (완전 공개)
   → 재현 가능성(reproducibility) 기여
```
