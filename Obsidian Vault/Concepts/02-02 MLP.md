# MLP (Peak-Aware Dual-Stream)

> 시계열이 아닌 lagged flat feature 기반 비선형 디코더. 하위 노드: [[02 - BCI Decoding]]

## 구조

- 입력 1: lagged spike feature (PCA 투영 또는 raw).
- 입력 2: peak-aware 거시 피처 5차원.
- 두 stream을 각각 FC로 비선형 매핑 후 concat → fusion → 2D velocity.

## 왜 Dual-Stream 인가

- PCA stream: 고차원 spike window의 핵심 subspace.
- Peak stream:
  - burst_score, active_ratio, onset_ratio.
  - velocity peak 구간의 급격한 변화를 explicit로 전달.
- Deep 모델이라 SER에서 오히려 noise를 학습할 위험도 있음.
- 결과:
  - baseline에서 최고 r=0.9209.
  - SER=1e-2에서 retention 0.9991.
  - 연결: `02 - SER & Error Models`
